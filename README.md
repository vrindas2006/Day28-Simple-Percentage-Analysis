# Day 28 - Simple Percentage Analysis

## 📌 Overview

This project is part of my Data Analytics learning journey.

In Day 28, I performed a simple percentage analysis using Microsoft Excel and the Superstore dataset. The analysis calculates the contribution of each product category to the overall sales.

## 🎯 Objective

- Calculate total sales by category
- Calculate the percentage contribution of each category
- Verify that the contribution percentages total 100%
- Visualize the contribution using a pie chart
- Understand how percentage contribution is used in business reporting

## 🛠️ Tools Used

- Microsoft Excel
- Superstore Dataset
- PivotTable
- PivotChart
- Excel formulas

## 📊 Analysis Performed

The analysis was performed for the following categories:

- Furniture
- Office Supplies
- Technology

### Contribution Formula

Contribution % = (Category Sales / Total Sales) × 100

## 📈 Key Results

| Category | Total Sales | Contribution % |
|----------|------------:|---------------:|
| Furniture | 741,999.7953 | 32.3% |
| Office Supplies | 719,047.0320 | 31.3% |
| Technology | 836,154.0330 | 36.4% |
| **Total** | **2,297,200.86** | **100%** |

## 🎤 Interview Questions Practiced

### What does percentage contribution mean?

Percentage contribution shows how much a particular category contributes to the overall total.

### Why must the denominator be stated?

The denominator defines the total against which the percentage is calculated and makes the result meaningful and interpretable.

### Why should contribution percentages total 100%?

When all categories are included, their individual contributions should represent the complete total, resulting in 100%.
